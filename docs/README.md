# Neural Bank Docs

Este diretório concentra a documentação técnica e as decisões arquiteturais do projeto.

## Estrutura

- `architecture/`: visão geral e ADRs.
- `database/`: modelo e decisões de persistência.
- `ai/`: arquitetura, experimentos e segurança de IA.
- `roadmap/`: evolução planejada do projeto.

A documentação deve evoluir junto com o código e permanecer versionada no repositório.
